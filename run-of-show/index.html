Rules for the night

FOUR
  • Never say “in orbit”, “deployed” or “transmitting.” On Oct 1 the temple is still inside the carrier. The “where it is now” view shows the carrier's predicted position. “They point to where it is” is true.
  • Every speech: the music comes down, Edson talks, the music goes back up. It never stops dead.
  • Use one verified number of names, or none.
  • The poem texts are public, but the performance is a surprise.
