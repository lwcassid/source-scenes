# SCRIM SURVEY — all 35 scenes, scored for the fabric
*An objective pass for the mesh-drape projection volume (2× Panasonic PT-VMZ50 via splitter, ~41ft throw, segmented mosquito-net surfaces).*

## The five criteria
A scene survives the fabric when: **(1)** it is discrete luminous elements on true black — black is invisible on mesh, only light exists; **(2)** it has no camera/perspective — any 2-foot fragment must read alone, because that's how the drapes will slice it; **(3)** its causality is one-second legible to a bystander; **(4)** its marks are fat, bright, saturated, and slow — thin lines, fine detail, and fast motion die on low-gain mesh at distance; **(5)** depth-echoing across multiple drapes makes it better, not worse. Scoring: **A** = scrim-native as it stands · **B** = strong after a focused pass · **C** = needs fundamental rework · **D** = screen piece, keep off the fabric.

## One shared rule for every pass
Simplify, don't add. Each scene keeps ONE mechanic a stranger understands in one second. Recent version passes added mechanics that read on a monitor and vanish in a fabric volume — the scrim pass is the subtraction pass.

## Sound (same recipe for everyone)
Set Live's tempo to the scene BPM. Channels: lead 1 / pad 2 / bass 3 / arp 4 / bells 5 / perc 10 / sfx 11. Use Drift for plucks (fast decay + dotted-8th Echo) and pads (two detuned saws, slow attack, Chorus-Ensemble); real samples for thunder/impacts on ch 11. Two returns: 6s Hybrid Reverb hall (~25% send from everything), synced Echo. Map **CC74 per channel → that instrument's filter cutoff** (each layer's energy, already streaming) and **CC1/CC2 (raw hands) → master Auto Filter + reverb send** so a moving hand is audible even between notes. Buffer 128.
