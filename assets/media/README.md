# assets/media — the files the MEDIA layers play

**Not committed** (gitignored, except this README). The build never bakes them into `index.html`. The show laptop carries them here, same names.

| file | layer | what |
|---|---|---|
| `launch.mp4` | SRC-77 · Launch Clip (a SHOT in Act I: knob 7 push / `L`) | the launch + separation, a few seconds, no countdown. **Alex cuts the real one on Oct 1, 16:00–20:00.** Since Sep 27 16:07: Edson's rocket clip (`~/Desktop/launch_clip_720.mov`, remuxed losslessly: H.264 1280×720, 29.97 fps, AAC, 33.6 s). The old generated placeholder is kept as `launch-placeholder.mp4`. |
| `temple.jpg` | SRC-78 · The Temple | a photograph of the Orbital Temple, **distributable** (the UARX integration photos are watermarked "Confidential. Do Not Distribute" and must not be used). |
| `qr.png` | SRC-79 · The QR | QR of `https://orbitaltemple.art` + the address, generated by `python3 -c "import qrcode…"` (see the session log). |

A missing file is not silent: the layer prints `MEDIA NOT FOUND · <title> · <path>` in its own frame.

Regenerate the placeholder clip:
```
ffmpeg -y -f lavfi -i "color=c=black:s=1920x1080:d=8:r=30" -f lavfi -i "sine=frequency=110:duration=8" \
  -filter_complex "[0:v]noise=alls=12:allf=t,drawbox=x='940+20*sin(t*3)':y='980-t*120':w=40:h=40:color=white@0.9:t=fill,drawtext=text='PLACEHOLDER CLIP':fontcolor=white@0.6:fontsize=36:x=(w-text_w)/2:y=h-80[v]" \
  -map "[v]" -map 1:a -c:v libx264 -pix_fmt yuv420p -c:a aac -shortest assets/media/launch.mp4
```
