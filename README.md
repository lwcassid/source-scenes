# source-scenes

The SOURCE Interaction Library — The Cave, Burning Man 2026. `index.html` is
the live site (Netlify auto-deploys `main`). Source lives in `parts/`,
assembled by `tools/build.sh`.

**Start here:** `CLAUDE.md` (project context, versioning law, lanes,
parallel-work rules) and the skills in `.claude/skills/` —
`scene-craft` (how scenes are built) and `sound-craft` (harmony engine,
three-layer soundscape doctrine).

**Guides & references:** `docs/KASIA-GUIDE.md` (collaborator quickstart),
`docs/SHOW-KIT.md` (running on-playa — the OFFLINE build is the show
artifact), instrument + scrim surveys in `docs/`.

**Tools:** `tools/playtest.js` (sighted verification; `SCENE=ALL` smokes
every scene), `tools/midi2chords.py` (reference MIDI → chord voicings),
`tools/build_preview.py` (self-contained offline build).
